# SIS Smart School — Master Architecture & Roadmap

Refer to the primary system documentation in the architecture folder.

## Core System Modules
1. **Multi-Tenant Foundation**: Dynamic tenant isolation using PostgreSQL Row-Level Security.
2. **Server-Driven UI (SDUI)**: Hierarchical runtime screen configuration for Flutter & Web.
3. **School Operations Suite**: Academics, Attendance, Examinations, GPA Engine, Fees & Invoicing.
4. **Communication & Notifications**: Push notification pipeline, system notices, announcements.
5. **Super Admin Platform Control**: Multi-school management, subscriptions, Remote App Control Center.
